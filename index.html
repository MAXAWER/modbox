MThread

Порядок в папке модов — и одна сборка на всю компанию.

Менеджер модов для Minecraft: Java Edition под Windows. Он читает вашу папку модов, объясняет, что в ней не так, и приводит её в порядок. А потом держит этот же набор у всех, с кем вы играете, — без сервера и без пересылки файлов вручную.

Моды

Каждый .jar разбирается, и то, что мод говорит о себе, сверяется с остальной папкой: версия игры, загрузчик, обязательные зависимости, конфликты, два файла под одним идентификатором, два мода, переписывающих один и тот же код игры. Всё это видно до того, как вы нажали «Играть».

Найти и поставить мод, ресурс-пак или шейдер можно не выходя из приложения. Состояние папки можно снять и вернуться к нему потом, а удалённое лежит в карантине и возвращается одним нажатием. Если игра всё-таки упала, ModBox читает краш-лог и называет файл, на котором она упала, вместо простыни из стектрейса.

Группы

Группа — это несколько человек и один набор модов на всех. Приглашение переезжает одной ссылкой; дальше приложение само сверяет, у кого чего не хватает, и достаёт недостающее у участника с самым низким пингом, а не с сайта. Сервер для этого не нужен: компьютеры соединяются напрямую.

Моды сверяются по содержимому файла, а не по имени: переименованный .jar остаётся тем же модом, и лишней раздачи не будет. Открыть мир для группы тоже можно из приложения — соединение идёт между компьютерами игроков.

MThread

Order in the mods folder — and one set of mods for everyone you play with.

A mod manager for Minecraft: Java Edition on Windows. It reads your mods folder, explains what is wrong with it, and puts it right. Then it keeps that same set on every machine in your group — with no server and no passing files around by hand.

Mods

Every .jar is parsed, and what a mod says about itself is checked against the rest of the folder: the game version, the loader, required dependencies, conflicts, two files claiming one identifier, two mods rewriting the same game code. All of it before you press Play.

Pre-flight check Minecraft 26.2 · Fabric · 25 mods

Will stop the game · 1 Likely to cause trouble · 1 Read without comment · 23

Mods, resource packs and shaders can be found and installed without leaving the application. A state of the folder can be taken and returned to later, and what you remove sits in quarantine and comes back with one press. If the game does fall over, ModBox reads the crash report and names the file it fell over on, instead of a wall of stack trace.

Groups

A group is several people and one set of mods between them. The invitation travels as a single link; from there the application works out who is missing what, and fetches the missing file from the member with the lowest ping rather than from a website. No server is needed: the computers connect to each other directly.

Group “Tuesday evening” 4 members · 25 mods
  • maxawer · made the group12 msset matches
  • dvornik19 msset matches
  • kotya41 msset matches
  • tenshi86 msmissing one mod: sodium
sodium-0.7.4.jar reaches tenshi from dvornik — of everyone who has that file, his ping is the lowest.

Mods are matched by the contents of the file, not by its name: a renamed .jar is still the same mod, and nothing is sent twice. Opening a world to the group happens from the application too — the connection runs between the players' own computers.
